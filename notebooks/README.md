# Notebooks

These notebooks are the interactive, experiment-focused entrypoints for the DGGR project.

Notes:
- Outputs are stripped before committing to keep diffs readable and repo size manageable.
- Most paths/data locations are configurable via CLI args or environment variables. See `docs/`.

Index:
- `01_lab1_deconstruction_encoder.ipynb`: Lab 1 curriculum training + audits (disentanglement + music gate).
- `02_lab2_genre_target_vector_space.ipynb`: Lab 2 target vector harvesting + centroid calibration + validation.
- `03_lab3_arch4_symmetry_pipeline.ipynb`: Early Lab 3 exploration notebook.
- `04_lab3_reconstruction_decoder.ipynb`: Lab 3 reconstruction/translation experiments.
- `05_lab3_sample_gallery.ipynb`: Sample visualization/listening utilities.
- `06_lab4_longform_remastering.ipynb`: Long-form synthesis pipeline (diffusion + codec comparisons).
- `07_lab4_longform_coherence_workbench.ipynb`: Main long-form coherence tuning workbench.
