# Presentation Deliverables

This folder is used to store the final presentation deliverables for the DGGR project.

## Final files

- `dggr_lecture_deck.pptx`: primary presentation file for class delivery.
- `dggr_lecture_deck.pdf`: static PDF copy of the slide deck.
- `dggr_speaker_script.pdf`: rehearsal script aligned to the final deck.

## Usage

- Present from `dggr_lecture_deck.pptx` when audio playback is needed.
- Use `dggr_lecture_deck.pdf` as the viewer-safe backup copy.
- Use `dggr_speaker_script.pdf` for rehearsal and presenter handoff.

## Notes

- The PowerPoint deck contains embedded demo audio clips.
- The PDF deck is intended as a static backup and may not support audio playback in every viewer.
