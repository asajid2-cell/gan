\section*{Objective}
Lab 1 establishes the deconstruction encoder used throughout the project. The goal is to separate short music clips into:
\begin{itemize}
  \item \textbf{$z_{\text{content}}$}: melody/rhythm/harmonic structure that should remain style-invariant
  \item \textbf{$z_{\text{style}}$}: genre and timbral cues that should remain style-informative
  \item \textbf{music gate}: a binary head that distinguishes music from non-music
\end{itemize}

The run summarized here is:

\vspace{0.5em}

\noindent Additional gate details from the same audit:
\begin{itemize}
  \item Gate accuracy at threshold $0.5$: 0.8602
  \item False positive rate at threshold $0.5$: 0.1361
  \item Music recall at threshold $0.5$: 0.8551
  \item When recalibrated to roughly 2\% FPR, recall drops to 0.5579
\end{itemize}

\section*{Interpretation}
\begin{itemize}
  \item \textbf{$z_{\text{style}}$ is working}: the style probe reaches 94.17\% accuracy, which means genre/source information is strongly present in the style branch.
  \item \textbf{$z_{\text{content}}$ is meaningfully disentangled}: leakage is only 0.1083 above the 0.5 chance baseline, so style information is substantially suppressed in the content branch.
  \item \textbf{The music gate separates classes well overall}: ROC AUC is 0.9299, which is strong enough for the demo story and downstream filtering.
  \item \textbf{The remaining weakness is calibration, not representation}: the gate passes the AUC threshold, but a strict low-FPR operating point still sacrifices recall. That means Lab 1 succeeds as a feature-learning stage even though the binary gate threshold can still be tuned later.
\end{itemize}

\section*{Why Lab 1 Matters for the Rest of the Pipeline}
These results justify using Lab 1 outputs in later stages:
\begin{itemize}
  \item Lab 2 uses the style-bearing side to build a target genre space.
  \item Lab 3 uses the content side as a melody-preservation anchor during remastering.
  \item Lab 4 relies on the same structural representation to preserve continuity over long-form generation.
\end{itemize}

\section*{Demo Takeaway}
For the demo, the key result is simple: \textbf{Lab 1 successfully produced a usable musical skeleton.} The content representation is sufficiently style-suppressed, the style representation is strongly discriminative, and the gate is reliable enough to separate music from non-music for downstream use.
