# Lab 5 - Final Evaluation

Lab 5 is the final perceptual-evaluation stage of the project.

## Purpose

This lab is reserved for the human-study and comparison phase:
- compare DGGR outputs against simpler filter-style baselines
- measure target-genre recognizability
- measure source-melody recognizability
- summarize listener preference and realism judgments

## Current Status

The implementation work in this repository reaches into Labs 1 through 4. Lab 5 remains the evaluation and reporting stage that should sit on top of those generated outputs and metrics.
