# Lab 4 - Long-Form Coherence

Lab 4 extends the short-form generation pipeline to longer musical sequences and focuses on keeping transitions, phrasing, and texture stable over time.

## What This Folder Contains

- `run_lab4_longform_coherence.py`: main long-form coherence entrypoint.
- `notebooks/06_lab4_longform_remastering.ipynb`: long-form remastering workflow notebook.
- `notebooks/07_lab4_longform_coherence_workbench.ipynb`: tuning and diagnostics notebook.
- `docs/01_quickstart_longform.md`: quickstart guide.
- `docs/lab4_longform.md`: Lab 4 overview.
- `docs/longform_coherence.md`: detailed coherence notes.
- `docs/longform_tuning.md`: practical tuning guide.

## Focus

Lab 4 introduces chunk overlap locking, source re-anchoring, and drift-control heuristics so the model can operate over full-song horizons instead of isolated five-second clips.
