# Architecture Decision Records (ADRs)

This folder tracks design decisions that materially affect reproducibility, quality, or collaboration.

Format:
- We use the MADR template style (see `docs/references.md`).
- Each ADR is numbered and immutable once accepted (update with a new ADR if needed).
